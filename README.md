# File Organizer

## Description
File Organizer est un outil développé en Python qui permet
de classer automatiquement les fichiers d'un dossier selon
leur extension.

## Fonctionnalités
- Organisation des documents.
- Organisation des images.
- Organisation des fichiers audio.
- Classement des fichiers non reconnus dans le dossier `autres`.
- Vérification de l'existence du dossier.
- Gestion des erreurs lors du déplacement des fichiers.

## Technologies utilisées
- Python
- pathlib
- shutil

## Installation
1. Télécharger ou cloner le projet.
2. Ouvrir le projet dans un éditeur Python.
3. Exécuter le programme.
