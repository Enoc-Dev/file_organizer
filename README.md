# File Organizer

## Description
File Organizer est un outil développé en Python qui permet de classer automatiquement les fichiers d'un dossier selon leur extension.

## Fonctionnalités
- Organisation des documents (`.pdf`, `.docx`, `.txt`).
- Organisation des images (`.jpg`, `.jpeg`, `.png`, `.gif`).
- Organisation des fichiers audio (`.mp3`, `.wav`, `.aiff`).
- Classement des fichiers non reconnus dans le dossier `autres`.
- Vérification de l'existence du dossier à organiser.
- Détection des fichiers portant le même nom.
- Demande de confirmation avant le remplacement d'un fichier.
- Possibilité d'annuler le remplacement.
- Gestion des erreurs lors du déplacement des fichiers.

## Technologies utilisées
- Python
- pathlib
- shutil

## Installation
1. Cloner ou télécharger le dépôt GitHub.
2. Ouvrir le projet dans un éditeur Python, comme PyCharm.
3. Vérifier que Python est installé.
4. Exécuter le fichier `core.py` depuis le dossier du projet.

## Utilisation
Placer les fichiers à organiser dans le dossier `A_trier`, puis lancer le programme.

Les fichiers seront classés automatiquement dans les sous-dossiers correspondants.
